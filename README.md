# ML Fraud Detection Service

DISCLAIMER

Сервис подготовлен в демонстрационных целях для студентов курса МТС ШАД 2026 в рамках занятий по MLOps.
Датасеты предоставлены в рамках соревнования https://www.kaggle.com/competitions/teta-ml-1-2025

Сервис для автоматического обнаружения мошеннических транзакций в режиме реального времени с использованием файлового вотчера. Обрабатывает CSV-файлы из указанной директории с использованием предобученной CatBoost модели.

## Ключевые особенности

### Реальное время обработки
- **Файловый вотчер**: Автоматическое обнаружение новых CSV-файлов в директории `input/`
- **Немедленная обработка**: Файлы обрабатываются сразу после появления
- **Пакетная обработка**: Возможность обработки нескольких файлов одновременно

### Многоуровневое логирование
- Регистрация всех событий в файл `/app/logs/service.log`
- Консольный вывод для мониторинга в реальном времени
- 3 уровня детализации:
  - `INFO`: Основные этапы обработки
  - `DEBUG`: Детали преобразования данных
  - `ERROR`: Критические сбои с трейсбэками

### Пайплайн обработки данных (`preprocessing_inference.py`)
1. **Очистка данных**:
   - Удаление ненужных колонок: `name_1`, `name_2`, `street`, `post_code`
   
2. **Временные признаки**:
   - Извлечение часа, дня недели, месяца, дня месяца, года
   - Преобразование в категориальные переменные
   - Удаление исходного `transaction_time`
   
3. **Геопространственные расчеты**:
   - Расчет расстояния (км) между клиентом и мерчантом
   - Использование `geopy.great_circle` для точных расчетов
   - Логарифмирование расстояния

4. **Категориальные переменные**:
   - Преобразование в строковый формат
   - Заполнение пропусков значением "unknown"
   - Обработка: `gender`, `merch`, `cat_id`, `one_city`, `us_state`, `jobs`

5. **Числовые признаки**:
   - Логарифмирование с добавлением 1 для avoiding log(0)
   - Обработка: `amount`, `population_city`

### Модельный слой (`scorer.py`)
- **Порог классификации**: 0.5 (настроен для оптимального баланса)
- **Бинарная классификация**: Возвращает 0/1 предсказания
- **Вероятностные оценки**: Использует `predict_proba` для получения уверенности модели
- **Автоматическая загрузка модели** при инициализации

### Визуализация и аналитика
- **Распределение предсказаний**: Сохранение графика `predictions_distribution.png`
- **Feature Importance**: Топ-5 наиболее важных признаков в `feature_importance.json`
- **Статистика предсказаний**: Логирование распределения классов и вероятностей

## Выходные данные

При обработке каждого файла сервис создает в директории `output/`:
1. **`sample_submission.csv`** - Основные предсказания с колонками:
   - `id`: идентификатор транзакции
   - `prediction`: бинарное предсказание (0/1)

2. **`feature_importance.json`** - Топ-5 важных признаков модели:
   ```json
   {
     "amount_log": 36.82,
     "cat_id": 35.96,
     "hour": 12.01,
     "one_city": 3.68,
     "merch": 2.40
   }
   ```

3. **`predictions_distribution.png`** - Визуализация распределения предсказанных вероятностей

## Быстрый старт

### Требования
- Docker 20.10+
- 2 ГБ свободного места
- Доступ к файловой системе

### Запуск сервиса

1. **Сборка образа**:
```bash
docker build -t fraud_detector .
```

2. **Запуск контейнера** с монтированием директорий:
```bash
docker run -it --rm \
  -v $(pwd)/input:/app/input \
  -v $(pwd)/output:/app/output \
  fraud_detector
```

3. **Использование сервиса**:
   - Поместите CSV-файл для анализа в директорию `input/`
   - Сервис автоматически обнаружит и обработает файл
   - Результаты появятся в директории `output/`
   - Следите за процессом через логи в консоли

### Пример данных

Для тестирования можно использовать файлы из соревнования https://www.kaggle.com/competitions/teta-ml-1-2025:
- `test.csv` - для скоринга
- `train.csv` - для справки (не требуется для работы сервиса)

- Автоматическое восстановление после ошибок
- Логирование производительности и статистики

- Распределение предсказаний

- Ошибки с полными трейсбэками
